API Architecture Overview

The application provides standard RESTful endpoints following HTTP verbs: GET (Retrieve), POST (Create), PUT (Update/Action), and DELETE (Remove). All responses are formatted in JSON with standard HTTP status codes (200 OK, 201 Created, 400 Bad Request, 404 Not Found).

1. Student REST Endpoints (Base: /api/students)
Method Endpoint Description Sample Payload / Notes
GET /api/students Retrieve list of all students Returns array of StudentDTO objects
GET /api/students/{id} Get single student by ID Returns 404 if not found
POST /api/students Add a new student 
{
  "fullName": "Kavya Reddy",
  "registerNumber": "2024CS109",
  "email": "kavya@college.edu",
  "phoneNumber": "+91 9876543299",
  "department": "Computer Science",
  "yearOfStudy": 2
}
PUT /api/students/{id} Update existing student record Accepts same JSON format as POST
DELETE /api/students/{id} Delete student record by ID Returns 200 with confirmation text
GET /api/students/department/{dept} HQL Query 1: Filter students by department e.g. /api/students/department/Computer Science
2. Room REST Endpoints (Base: /api/rooms)
Method Endpoint Description Sample Payload
GET /api/rooms Get all rooms Returns all rooms with capacity, occupied beds, and available beds
GET /api/rooms/available Get only available rooms Returns rooms where status is 'AVAILABLE'
POST /api/rooms Create a new room 
{
  "roomNumber": "D-401",
  "buildingName": "Ganga Hostel",

  "capacity": 2,
  "occupiedBeds": 0,
  "monthlyRent": 4800.0

3. Booking REST Endpoints (Base: /api/bookings)
Method Endpoint Description Sample Payload
GET /api/bookings Retrieve all bookings Includes student and room details in response
GET /api/bookings/{id} Get booking by ID Returns booking details or 404
POST /api/bookings Create a new booking 
{
  "studentId": 3,
  "roomId": 3,
  "bookingDate": "2026-10-19"
}
PUT /api/bookings/{id}/cancel Cancel booking and release bed Updates status to CANCELLED and decrements room occupied count
GET /api/bookings/student/{studentId}/active HQL Query 2: Get active booking for student e.g. /api/bookings/student/1/active
